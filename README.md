# Marketing Lab

> **Marketing Insights Lab** · British Management University  
> *Think like marketers. Act like analysts. Create like professionals.*

A student-driven marketing publication and professional community connected to British Management University.

## Overview
- **Publications**: Research, campaign analyses, news, and student-authored marketing insights.
- **Community & Events**: Workshops, guest lectures, and student networking.
- **Portfolio Building**: Editorial support helping student marketers publish real industry-relevant work.

- `index.html` / `Marketing Lab.html` — Interactive web application and publication portal.
